KEEP THE CROWD ALIVE - ARENA ZONE & CROWD LIGHTPOINT CODE PLAN
Target: HTML5 / Phaser 3 / TypeScript / Visual Studio Code

==================================================
WHAT THIS FILE CONTAINS
==================================================

This file defines a first technical arena model for the festival map.

It includes:
- named arena zones
- entrance and exit gates
- stairs / ramps / radial corridors
- crowd rings
- tower placement zones
- enemy lanes
- lightpoint visitor simulation
- path definitions for moving crowd lights
- code-ready TypeScript structures

The visual assumption:
Because the camera is far above the festival, visitors do not need detailed bodies.
Visitors are represented as glowing lightpoints.

These lightpoints:
- enter through gates
- move along defined paths
- fill crowd zones
- react to hype
- flee through exits during panic
- pulse with the music beat

==================================================
CORE MAP IDEA
==================================================

Arena shape:
- circular amphitheater / futuristic festival bowl
- central stage core
- multiple concentric crowd rings
- radial stairs and corridors
- outer access ring
- entrance gates around the arena

Main gameplay:
- visitors flow into the arena as lightpoints
- enemies infiltrate through gates and corridors
- the crowd becomes the emotional health system
- tower placements happen around strategic ring/corridor zones
- panic causes crowd lightpoints to move toward exits

==================================================
COORDINATE SYSTEM
==================================================

Recommended coordinate system:
- arena center = { x: 0, y: 0 }
- positive x = right
- positive y = down
- all positions are local world coordinates
- Phaser can later offset this by camera/world center

Suggested first map size:
- width: 2400
- height: 1600
- center in Phaser screen/world: { x: 1200, y: 800 }

In the code below, coordinates are relative to arena center.
When rendering, add ARENA_WORLD_OFFSET.

export type ArenaZone = {
  id: ZoneId;
  type: ZoneType;
  label: string;

  // Center position relative to arena center.
  center: Vec2;

  // For circular / oval zones.
  radius?: number;
  innerRadius?: number;
  outerRadius?: number;

  // For angled ring segments.
  angleStartDeg?: number;
  angleEndDeg?: number;

  // For rectangular zones.
  width?: number;
  height?: number;
  rotationDeg?: number;

  // Gameplay values.
  capacity?: number;
  currentCrowd?: number;
  hypeMultiplier?: number;
  panicRisk?: number;
  corruptionRisk?: number;

  // Use this to mark whether towers can be placed here.
  buildable?: boolean;

  // Use this to mark whether enemies can pass through.
  enemyAccessible?: boolean;

  // Use this to mark whether crowd can move through.
  crowdAccessible?: boolean;
};

export type PathNode = {
  id: string;
  position: Vec2;
  zoneId: ZoneId;
};

export type PathDefinition = {
  id: string;
  label: string;
  nodeIds: string[];
  allowedFor: Array<"crowd" | "enemy" | "panic" | "service">;
  speedMultiplier: number;
  width: number;
};

export type LightPointVisitor = {
  id: number;
  position: Vec2;
  targetNodeIndex: number;
  pathId: string;
  state: CrowdState;

  // Visual settings.
  baseRadius: number;
  glowRadius: number;
  alpha: number;

  // Gameplay / animation.
  speed: number;
  hypeResponsiveness: number;
  panicSensitivity: number;
  beatPhaseOffset: number;

  // Optional zone tracking.
  currentZoneId?: ZoneId;
  targetZoneId?: ZoneId;
};

- move down stairs
- spread into crowd rings

- spawn at corrupted gates
- use stairs/corridors
- attempt to reach crowd rings or stage core

import Phaser from "phaser";
import {
  Vec2,
  LightPointVisitor as LightPointVisitorData,
  PathDefinition,
  PathNode,
  ARENA_WORLD_OFFSET,
} from "../../data/arenaConfig";
import { CROWD_LIGHT_CONFIG } from "../../data/crowdLightConfig";

export class LightPointVisitor {
  public data: LightPointVisitorData;
  private graphics: Phaser.GameObjects.Arc;
  private glow: Phaser.GameObjects.Arc;

  constructor(
    scene: Phaser.Scene,
    id: number,
    start: Vec2,
    pathId: string,
    state: LightPointVisitorData["state"] = "entering"
  ) {
    const worldX = start.x + ARENA_WORLD_OFFSET.x;
    const worldY = start.y + ARENA_WORLD_OFFSET.y;

    this.data = {
      id,
      position: { ...start },
      targetNodeIndex: 0,
      pathId,
      state,
      baseRadius: CROWD_LIGHT_CONFIG.baseRadius,
      glowRadius: CROWD_LIGHT_CONFIG.baseGlowRadius,
      alpha: 0.85,
      speed: CROWD_LIGHT_CONFIG.enteringSpeed,
      hypeResponsiveness: Math.random() * 0.5 + 0.5,
      panicSensitivity: Math.random() * 0.8 + 0.2,
      beatPhaseOffset: Math.random() * Math.PI * 2,
    };

    this.glow = scene.add.circle(
      worldX,
      worldY,
      CROWD_LIGHT_CONFIG.baseGlowRadius,
      CROWD_LIGHT_CONFIG.colors.entering,
      0.18
    );

    this.graphics = scene.add.circle(
      worldX,
      worldY,
      CROWD_LIGHT_CONFIG.baseRadius,
      CROWD_LIGHT_CONFIG.colors.entering,
      0.9
    );

    this.glow.setBlendMode(Phaser.BlendModes.ADD);
    this.graphics.setBlendMode(Phaser.BlendModes.ADD);
  }

  update(
    deltaMs: number,
    path: PathDefinition,
    nodesById: Map<string, PathNode>,
    globalHype: number,
    beatValue: number
  ) {
    const deltaSeconds = deltaMs / 1000;
    const targetNodeId = path.nodeIds[this.data.targetNodeIndex];

    if (!targetNodeId) {
      this.applyDancingMotion(deltaSeconds, globalHype, beatValue);
      this.updateVisuals(globalHype, beatValue);
      return;
    }

    const targetNode = nodesById.get(targetNodeId);
    if (!targetNode) return;

    const target = targetNode.position;
    const dx = target.x - this.data.position.x;
    const dy = target.y - this.data.position.y;
    const distance = Math.sqrt(dx * dx + dy * dy);

    if (distance < 8) {
      this.data.currentZoneId = targetNode.zoneId;
      this.data.targetNodeIndex++;
    } else {
      const dirX = dx / distance;
      const dirY = dy / distance;

      const speed = this.getCurrentSpeed() * path.speedMultiplier;

      this.data.position.x += dirX * speed * deltaSeconds;
      this.data.position.y += dirY * speed * deltaSeconds;
    }

    this.updateVisuals(globalHype, beatValue);
  }

  setState(state: LightPointVisitorData["state"]) {
    this.data.state = state;
  }

  setPath(pathId: string) {
    this.data.pathId = pathId;
    this.data.targetNodeIndex = 0;
  }

  destroy() {
    this.graphics.destroy();
    this.glow.destroy();
  }

  private getCurrentSpeed(): number {
    switch (this.data.state) {
      case "panic":
        return CROWD_LIGHT_CONFIG.panicSpeed;
      case "leaving":
        return CROWD_LIGHT_CONFIG.panicSpeed * 0.9;
      case "entering":
        return CROWD_LIGHT_CONFIG.enteringSpeed;
      case "dancing":
      case "highHype":
      default:
        return CROWD_LIGHT_CONFIG.baseSpeed;
    }
  }

  private applyDancingMotion(deltaSeconds: number, globalHype: number, beatValue: number) {
    const drift = CROWD_LIGHT_CONFIG.dancingDriftSpeed;
    const intensity = 0.4 + globalHype * 0.8;

    this.data.position.x +=
      Math.cos(performance.now() * 0.002 + this.data.beatPhaseOffset) *
      drift *
      intensity *
      deltaSeconds;

    this.data.position.y +=
      Math.sin(performance.now() * 0.002 + this.data.beatPhaseOffset) *
      drift *
      intensity *
      deltaSeconds;

    if (beatValue > 0.85 && this.data.state !== "panic") {
      this.data.position.y -= 0.8 * intensity;
    }
  }

  private updateVisuals(globalHype: number, beatValue: number) {
    const state = this.data.state;
    const color = CROWD_LIGHT_CONFIG.colors[state];

    let radius = CROWD_LIGHT_CONFIG.baseRadius;
    let glowRadius = CROWD_LIGHT_CONFIG.baseGlowRadius;
    let alpha = 0.75;

    if (state === "highHype") {
      radius = CROWD_LIGHT_CONFIG.highHypeRadius;
      glowRadius = CROWD_LIGHT_CONFIG.highHypeGlowRadius;
      alpha = 0.95;
    }

    if (state === "panic") {
      radius = CROWD_LIGHT_CONFIG.panicRadius;
      glowRadius = CROWD_LIGHT_CONFIG.panicGlowRadius;
      alpha = 0.9;
    }

    const pulseAmount = CROWD_LIGHT_CONFIG.beatPulseScale[state];
    const pulse = 1 + beatValue * pulseAmount * (0.5 + globalHype);

    const worldX = this.data.position.x + ARENA_WORLD_OFFSET.x;
    const worldY = this.data.position.y + ARENA_WORLD_OFFSET.y;

    this.graphics.setPosition(worldX, worldY);
    this.glow.setPosition(worldX, worldY);

    this.graphics.setFillStyle(color, alpha);
    this.glow.setFillStyle(color, 0.12 + globalHype * 0.18);

    this.graphics.setRadius(radius * pulse);
    this.glow.setRadius(glowRadius * pulse);
  }
}

import Phaser from "phaser";
import {
  PATHS,
  PATH_NODES,
  PathDefinition,
  PathNode,
} from "../data/arenaConfig";
import { LightPointVisitor } from "../entities/crowd/LightPointVisitor";
import { CROWD_LIGHT_CONFIG } from "../data/crowdLightConfig";

export class CrowdFlowSystem {
  private scene: Phaser.Scene;
  private visitors: LightPointVisitor[] = [];
  private nodesById: Map<string, PathNode> = new Map();
  private pathsById: Map<string, PathDefinition> = new Map();

  private nextVisitorId = 1;
  private spawnTimerMs = 0;

  constructor(scene: Phaser.Scene) {
    this.scene = scene;

    for (const node of PATH_NODES) {
      this.nodesById.set(node.id, node);
    }

    for (const path of PATHS) {
      this.pathsById.set(path.id, path);
    }
  }

  update(deltaMs: number, globalHype: number, beatValue: number) {
    this.spawnTimerMs += deltaMs;

    // More hype means more visitors entering.
    const spawnInterval = Phaser.Math.Linear(900, 180, globalHype);

    if (
      this.spawnTimerMs >= spawnInterval &&
      this.visitors.length < CROWD_LIGHT_CONFIG.maxVisitors
    ) {
      this.spawnTimerMs = 0;
      this.spawnVisitor(globalHype);
    }

    for (const visitor of this.visitors) {
      const path = this.pathsById.get(visitor.data.pathId);
      if (!path) continue;

      visitor.update(deltaMs, path, this.nodesById, globalHype, beatValue);

      if (globalHype > 0.75 && visitor.data.state !== "panic") {
        visitor.setState("highHype");
      } else if (globalHype > 0.35 && visitor.data.state !== "panic") {
        visitor.setState("dancing");
      } else if (visitor.data.state !== "panic") {
        visitor.setState("idle");
      }
    }
  }

  triggerPanic(sourceDirection: "north" | "east" | "south" | "west") {
    for (const visitor of this.visitors) {
      if (Math.random() > visitor.data.panicSensitivity) continue;

      visitor.setState("panic");

      switch (sourceDirection) {
        case "north":
          visitor.setPath("PANIC_RING_A_TO_SOUTH_EXIT");
          break;
        case "east":
          visitor.setPath("PANIC_RING_A_TO_WEST_EXIT");
          break;
        case "south":
          visitor.setPath("PANIC_RING_A_TO_NORTH_EXIT");
          break;
        case "west":
          visitor.setPath("PANIC_RING_A_TO_EAST_EXIT");
          break;
      }
    }
  }

  triggerCorruption(amount: number) {
    const count = Math.floor(this.visitors.length * amount);

    for (let i = 0; i < count; i++) {
      const visitor = Phaser.Utils.Array.GetRandom(this.visitors);
      if (visitor) {
        visitor.setState("corrupted");
      }
    }
  }

  getCrowdCount(): number {
    return this.visitors.length;
  }

  private spawnVisitor(globalHype: number) {
    const entryPaths = [
      "CROWD_ENTRY_NORTH_TO_RING_A",
      "CROWD_ENTRY_EAST_TO_RING_A",
      "CROWD_ENTRY_SOUTH_TO_RING_A",
      "CROWD_ENTRY_WEST_TO_RING_A",
      "CROWD_ENTRY_NE_TO_RING_C",
      "CROWD_ENTRY_SE_TO_RING_C",
      "CROWD_ENTRY_SW_TO_RING_C",
      "CROWD_ENTRY_NW_TO_RING_C",
    ];

    const pathId = Phaser.Utils.Array.GetRandom(entryPaths);
    const path = this.pathsById.get(pathId);
    if (!path) return;

    const firstNode = this.nodesById.get(path.nodeIds[0]);
    if (!firstNode) return;

    const jitter = CROWD_LIGHT_CONFIG.pathJitter.normal;

    const start = {
      x: firstNode.position.x + Phaser.Math.Between(-jitter, jitter),
      y: firstNode.position.y + Phaser.Math.Between(-jitter, jitter),
    };

    const visitor = new LightPointVisitor(
      this.scene,
      this.nextVisitorId++,
      start,
      pathId,
      globalHype > 0.7 ? "highHype" : "entering"
    );

    this.visitors.push(visitor);
  }
}

export class BeatClock {
  private bpm: number;
  private elapsedMs = 0;

  constructor(bpm: number = 128) {
    this.bpm = bpm;
  }

  update(deltaMs: number) {
    this.elapsedMs += deltaMs;
  }

  getBeatValue(): number {
    const beatDurationMs = 60000 / this.bpm;
    const phase = (this.elapsedMs % beatDurationMs) / beatDurationMs;

    // Sharp pulse at the start of the beat.
    return Math.max(0, 1 - phase * 3);
  }

  getBarProgress(beatsPerBar: number = 4): number {
    const beatDurationMs = 60000 / this.bpm;
    const barDurationMs = beatDurationMs * beatsPerBar;
    return (this.elapsedMs % barDurationMs) / barDurationMs;
  }
}

    const beatValue = this.beatClock.getBeatValue();

==================================================
HOW THIS DEFINES THE ARENA
==================================================

Zones:
- STAGE_CORE is the center target and emotional heart.
- STAGE_PLATFORM surrounds the core.
- INNER_DANCE_FLOOR is the closest high-energy crowd zone.
- CROWD_RING_A/B/C are main visitor zones.
- VIP_RING is high-value crowd.
- OUTER_CONCOURSE is the circulation ring.
- Gates are entry points.
- Stairs are radial movement corridors.
- Tower decks are buildable platforms.
- Safe exits are panic destinations.
- Service backstage is a sabotage target.

Crowd:
- represented by glowing dots
- enters through gates
- moves through paths
- fills rings
- pulses to beat
- changes color/state with hype and panic

Enemies:
- use the same logical nodes
- can be routed through gates and stairs
- target crowd, backstage, or stage core
